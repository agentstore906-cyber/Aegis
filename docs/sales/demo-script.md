# Demo script (10–15 minutes)

Uses the real `/demo` route and, if the prospect signs up during or after
the call, the real seeded Northstar Labs organization (`npm run db:seed`)
— not slides. Every scenario below is real seed data generated by
actually running it through the policy/security engine, not hand-faked
JSON (see `prisma/seed.ts`). Sign-in credentials for the seeded org are in
`README.md`.

## 0–2 min — Problem

Open with one question, not a pitch: *"How are you governing your AI
agents in production today?"* Let them answer. Most answers land on
"we're not, really" or "it's ad hoc per team." Bridge to: Aegis is the
control plane that sits between an agent and the action it's about to
take.

## 2–4 min — Agent overview

`/agents` — Northstar Labs has six agents (Sales, Support, Finance,
Research, Coding, Deployment), each with baseline permissions. Click into
Finance Agent: show its permission list (`refund.issue` →
`REQUIRE_APPROVAL`, `invoice.delete` → `BLOCK`, `bank_account.change` →
`BLOCK`). This is the floor — what the agent can do at all, before any
conditional policy layers on top.

## 4–6 min — Activity

`/activity` — structured, filterable event log. Point out this isn't a
raw log dump: `status`, `riskLevel`, `eventType`, `traceId` are real
columns, not buried in JSON, because the rest of the product (cost,
policy, audit) queries them directly.

## 6–8 min — Policy

`/policies` — open the seeded policy *"Large refunds always need a human
to sign off before they go out"*: scope is Finance Agent, action
`refund.issue`, condition `context.amount > 500`, decision
`REQUIRE_APPROVAL`. Use `/policies/test` live: run a `refund.issue` at
`amount: 250` (ALLOW) and `amount: 1250` (REQUIRE_APPROVAL) — the same
engine, not a canned response.

## 8–10 min — Approval

`/approvals` — the seeded $1,250 Acme Inc. refund request is sitting
`PENDING`. Approve it live. Show the resulting `ApprovalDecision` and that
it's now visible in `/audit` by trace id — the whole chain from the
original event to the human decision is one linked record, not
reconstructed after the fact.

## 10–12 min — Security

`/security` — the Sales Agent's `crm.export` attempt: blocked (no
permission allows it), and because it's a first-ever attempt at a
HIGH-risk blocked action, it also tripped a `CRITICAL` security alert
(`detectNewSensitiveAction`). Explain these are deterministic detectors
with structured evidence, not an opaque ML score — the prospect's security
lead will ask this.

## 12–14 min — Cost

`/costs` — Research Agent's cost-spike scenario: a ~$12/day baseline for a
week, then a ~$94 day. That's the same `SecurityAlert` system filtered by
type, not a second product bolted on.

## 14–15 min — Next steps

Don't close hard in the demo. Offer:

1. A free account — `/sign-up`, no credit card, limits are real but not
   crippling (3 agents, 7-day activity on Free).
2. A pilot — see `docs/sales/objections.md` and the pilot structure in
   `AGENTS.md` §49 if this is a 5+ agent, sensitive-data org.
3. If genuinely Enterprise-shaped (10+ agents, compliance requirements,
   multiple teams): route to `/contact?source=enterprise`.

## What NOT to do in this demo

- Don't claim integrations that don't exist (see
  `docs/sales/objections.md` — "does it work with LangGraph/CrewAI").
- Don't imply Aegis executes the agent's action — it only decides and
  reports. Say this explicitly if asked.
- Don't show `/admin/leads` or any internal tooling.

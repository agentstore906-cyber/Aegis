# Weekly GTM loop

The repeatable weekly cycle during founder-led sales (`AGENTS.md` §56,
§63). Not a rigid schedule — a checklist of what should happen every
week, in roughly this order.

## 1. Research target accounts

Add real accounts to a target-account list using
`docs/sales/target-account-template.md`'s structure. Quality over volume —
a well-researched pain hypothesis beats ten generic rows.

## 2. Contact prospects

Send personalized outreach using `docs/sales/outreach.md` as a starting
point, never sent unedited. Track status in the pipeline
(`TARGET → RESEARCHED → CONTACTED → ...`).

## 3. Run demos

Use `docs/sales/demo-script.md` against the real `/demo` route or a real
seeded environment. Every demo either books a next step or gets an honest
"not a fit right now" — no demo should end ambiguously.

## 4. Onboard trials

Anyone who signs up gets to first value fast — connect an agent, see a
real decision, in under 10 minutes (`/developers/quickstart`). Watch for
where they actually get stuck, not where you assume they will.

## 5. Interview customers

Run `docs/customer-research/interview.md` with anyone willing — trial
users, pilot customers, even prospects who didn't convert. A "no" with a
real reason is more useful than a polite non-answer.

## 6. Identify problems

Log everything from step 5 into `docs/customer-feedback.md` — one row per
distinct piece of feedback, their words, not a summary that already fits
what you want to hear.

## 7. Improve product

Run the week's feedback through
`docs/customer-research/feature-prioritization.md`. Most weeks this
should not result in a new large feature — see `AGENTS.md` §85's closing
principle: after Phase 8, the default is sell/learn/improve, not build.

## 8. Follow up

Work the follow-up sequence in `docs/sales/outreach.md` for anyone mid-
pipeline. Don't let a promising thread go cold because a new week started.

## 9. Measure conversion

Look at the real funnel numbers — signups, activation (agent connected +
first event + first policy + first evaluation), demo requests, trial →
paid. Never estimate or round up a number that doesn't exist yet; an
empty funnel stage is information, not a gap to paper over.

## Weekly review questions

- What did we learn this week that we didn't know last week?
- What's the one blocker preventing the next deal/pilot from moving?
- Did we talk to fewer real customers than last week, and why?
